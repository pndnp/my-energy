# Proposal: MVP Full Application — «Энергия дня»

## Why

Существует инициализированный frontend проект, но бэкэнд, база данных и основная функциональность приложения отсутствуют. Необходимо реализовать полное веб-приложение для наблюдения за самочувствием и поиска закономерностей между привычками и уровнем энергии — от авторизации до AI-наблюдений.

## What Changes

- **Backend на Node.js + TypeScript** с REST API
- **PostgreSQL база данных** со схемой `daily_logs`
- **Авторизация**: регистрация, вход, выход, управление сессией
- **Daily Logs CRUD**: создание, чтение, обновление дневных записей (9 метрик, шкала 1–5)
- **Dashboard**: главный экран с формой ввода, графиком энергии за 7 дней, AI-наблюдением
- **History**: календарь, список дней, подробности выбранного дня
- **Analytics**: выбор периода, summary, графики сравнения показателей, связи с энергией, лучшие/худшие дни
- **AI Insights**: расчёт статистики backend → передача в LLM → структурированные наблюдения
- **Frontend pages**: реализация всех страниц с использованием shadcn/ui компонентов
- **Docker Compose** конфигурация для деплоя

## Capabilities

### New Capabilities

- `auth`: регистрация, вход, выход, проверка пользователя, управление сессией через REST API
- `daily-logs`: CRUD операций для дневных записей — создание одной записи на пользователя за день, 9 метрик (1–5), уникальность по user_id + date
- `dashboard`: основной экран с формой редактирования, текущими показателями, мини-графиком энергии за 7 дней, кратким AI-наблюдением
- `history`: календарь, список дней с уровнем энергии, детальный просмотр выбранного дня
- `analytics`: выбор периода (7/14/30/90 дней), summary средних значений, графики сравнения нескольких показателей, анализ связей показателей с энергией, определение лучших/худших дней
- `ai-insights`: расчёт статистики backend → вызов LLM API с контекстом → парсинг structured JSON → отображение наблюдений и экспериментов во frontend
- `api-design`: единый REST API контракт между frontend и backend, middleware авторизации, валидация входных данных

## Impact

- Создание новых директорий: `backend/src/` c модулями, `docker-compose.yml`, `.env.example`
- Новая структура базы данных: таблица `daily_logs` с 9 числовыми полями
- Зависимости backend: express/node, postgres/driver, LLM SDK (изоляция провайдера)
- Изменения frontend: новые страницы, хуки, API клиент, навигация
- DevOps: Docker Compose для локальной разработки и продакшена
